# assets/ — шаблоны UI для blockade_ai.py

Здесь лежат маленькие скриншоты элементов интерфейса BLOCKADE. Бот ищет их на
экране через matchTemplate и понимает: «я убил», «я умер», «это меню команды»,
«это кнопка Бой». Все шаблоны нужно переснять ЗАНОВО под твой ник и твой UI —
файлы потерялись вместе с проектом.

## Как сделать шаблоны (быстрый способ)

1. Зайди в BLOCKADE, дойди до нужного экрана (бой / экран смерти / меню).
2. Запусти помощник:
   ```
   python -I tools/make_assets.py
   ```
3. Он сделает скриншот через 5 секунд, потом по очереди попросит мышкой
   выделить рамкой каждый элемент и сохранит его в assets/.

Вручную: Win+Shift+S → обрезать элемент → сохранить PNG в эту папку.

## Какие файлы нужны

| Файл | Что вырезать | Обязательность |
|---|---|---|
| `aponima_feed.png` | Строку killfeed со СВОИМ ником (правый верхний угол, момент когда ты кого-то убил). Ник должен гореть ярко. Если ник не `aponima` — файл всё равно называется так же (путь в config.json: kill_template_path), либо переименуй и поправь конфиг. | **Да** — без него нет награды за фраги, обучение почти бесполезно |
| `respawn_lmb.png` | Надпись «нажмите ЛКМ для возрождения» (или как она выглядит у тебя) с экрана смерти | Желательно — ускоряет выход из смерти |
| `team_select.png` | Жёлтую кнопку «АВТО» в меню выбора команды | Желательно — бот сам заходит в бой |
| `battle_button.png` | Кнопку «Бой» в лобби (если есть) | Нет — опционально |

## Проверка после создания

```
python -I tools/check_assets.py
```
Покажет размеры файлов и совпадение с текущим экраном (если игра открыта).

## Советы

- Вырезай ВПЛОТНУ к элементу, без лишнего фона — matchTemplate чувствителен к
  мусору вокруг.
- Killfeed: вырезай только ник + иконку оружия, без ника жертвы.
- Шаблоны снимаются на том разрешении, на котором играешь. Сменил разрешение —
  пересними.
- Цвет ника в killfeed меняется от команды — это нормально: KillDetector
  бинаризует по яркости (HSV V-канал), цвет не важен.
