# PPO Models

Directory reserved for PPO (Proximal Policy Optimization) checkpoints generated using Stable-Baselines3.

No trained PPO models are currently included. YOLO weights in the repository root are separate computer vision models.

## Русский

Папка для обученных PPO-моделей и контрольных точек обучения. Сейчас готовые PPO-модели отсутствуют. Веса YOLO не заменяют модели PPO.
